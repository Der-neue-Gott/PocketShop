# PocketShop - Photo Editor

Интерактивный минималистичный клиентский фоторедактор, написанный на чистом TypeScript с использованием HTML5 Canvas API.

🚀 **[Попробовать редактор онлайн](ССЫЛКА_НА_VERCEL)**

## 🛠 Технологии
- **Frontend:** TypeScript, Native HTML5 Canvas API, CSS3
- **Сборка:** Vite
- **Деплой:** Vercel

## ✨ Функционал
- **Работа со слоями:** добавление нескольких текстовых блоков и дополнительных изображений на холст.
- **Трансформация:** перетаскивание (Drag & Drop) по холсту, масштабирование и поворот объектов за "ручки".
- **Фильтры основного фото:** регулировка яркости, контраста, размытия и готовые пресеты (Ч/Б, Сепия, Инверсия).
- **История действий:** поддержка отмены и повтора изменений (Undo / Redo, горячие клавиши `Ctrl+Z` / `Ctrl+Y`).
- **Мобильная адаптивность:** обработка Touch-событий для смартфона и Drag & Drop файлов с рабочего стола.
